# Security policy

Report vulnerabilities privately through GitHub Security Advisories for this repository. Do not include credentials, approval-state files, private transcripts, or exploit details in a public issue.

Clonamic plugins and hooks run with the host agent's privileges. Review source and release checksums before installation. The project treats path traversal, symlink escape, approval confusion, secret exposure, and incomplete rollback as security defects.

Supported security updates are provided for the latest release.

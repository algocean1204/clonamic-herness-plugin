# Clonamic Report

The first non-blank line states the result and one key number or cause. A response with four or more non-blank lines is one flat list.

Report only facts that change the reader's understanding:

- failures and unverified required items first;
- requested outputs and acceptance counts;
- fresh verification evidence;
- actual apply, deploy, publish, or backup state when those actions were in scope;
- material residual risk.

Use natural Korean for Korean conversations. Keep identifiers and commands unchanged. Prefer numbers to adjectives. Do not narrate tool order, restate the request, repeat the conclusion, or close with an offer to continue.

If a required item is unresolved, write a blocker report. Never label it completion.

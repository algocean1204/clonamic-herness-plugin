# Benchmark method

Use a clean temporary Git repository and run the same requests on every platform:

1. Read the current branch.
2. Correct one exact typo.
3. Implement a two-file parser with tests.
4. Resume after each approval.
5. Inject a failing test and a false completion claim.

Record wall time, model turns, input/cache/output tokens, tool calls, approval count, changed files, test results, progress-message count, and residual files after uninstall.

Do not publish scores without the raw transcript, tool version, model selector, reasoning effort, repository fixture hash, and date.
